# 🧒 Kidsnote Memories Saver (키즈노트 추억 저장기)

> 키즈노트(kidsnote.com)에 올라온 **우리 아이의 알림장과 앨범을 내 컴퓨터로 한 번에 백업**하는 윈도우용 프로그램입니다.
> 설치 없이 실행만 하면 되고, 모든 자료는 내 PC에만 저장됩니다.

## 💛 왜 만들었나요?

아이가 어린이집·유치원을 다니는 동안 쌓인 알림장과 사진은 부모에게 무엇과도 바꿀 수 없는 기록입니다.
하지만 졸업하거나 퇴소하면 열람이 어려워지고, 하나씩 저장하기엔 양이 너무 많습니다.

이 프로그램은 **부모가 이미 볼 수 있는 내 아이의 기록을, 사라지기 전에 내 손에 안전하게 옮겨두기 위해** 만들었습니다.

---

## ✨ 주요 기능

- 📋 **알림장 저장** — 댓글까지 포함된 전체 화면을 PDF로 보존
- 📸 **앨범 사진·동영상 저장** — 원본 화질 그대로 날짜별 폴더에 정리
- 🆕 **PDF + 사진 동시 저장** — 한 번의 다운로드로 둘 다 같은 폴더에 저장
- 📅 **기간 선택** — 최근 1주일 / 1개월 / 3개월 / 6개월 / 1년, 또는 달력으로 직접 지정
- 🔄 **증분 백업** — 이미 받은 항목은 표시되고, [새 항목만 선택]으로 신규분만 저장
- 👶 **다자녀 지원** — 아이가 여러 명이어도 콤보박스로 즉시 전환
- 🗂️ **똑똑한 정리** — 사진 날짜를 파일 시간에 기록해 갤러리에서 추억 순으로 정렬
- 🛡️ **오류 자동 복구** — 키즈노트 사이트 오류 화면을 감지해 자동으로 다시 시도
- 🌐 **까다로운 네트워크 대응** — 사진 다운로드가 막히면 여러 우회 경로를 자동으로 시도
- 🖥️ **4K 고해상도 지원** — 고해상도 모니터에서도 UI가 작아지지 않습니다

## 🚀 시작하기

### 1️⃣ 다운로드

[**Releases 페이지**](../../releases/latest)에서 최신 `Kidsnote_Release_Vx.xx.zip` 파일을 받습니다.

### 2️⃣ 실행

압축을 풀고 폴더 안의 **`Kidsnote_Memories_Saver_Vx.xx.exe`** 를 더블클릭하세요.
(폴더 안의 다른 파일들은 프로그램 구동용이니 지우지 마세요.)

> **필요한 것은 Microsoft Edge 브라우저뿐입니다.** 윈도우에 기본 설치되어 있으므로 별도 준비가 필요 없습니다.

### 3️⃣ 3단계로 저장

| 단계 | 할 일 |
|:---:|---|
| **1** | 키즈노트 아이디·비밀번호로 로그인 → 아이 선택 |
| **2** | 조회 기간을 고르고 **[추억 목록 불러오기]** |
| **3** | 저장할 항목을 체크하고 **[다운로드 시작]** |

> [!TIP]
> **Windows SmartScreen 경고가 뜬다면?**
> 개인이 만든 무료 프로그램이라 코드 서명 인증서가 없어 발생하는 정상적인 경고입니다.
> **[추가 정보] → [실행]** 을 누르시면 됩니다. 소스 코드는 이 저장소에 전부 공개되어 있습니다.

## 🔐 개인정보는 안전한가요?

아이 사진이 걸린 만큼, 이 부분을 가장 신경 썼습니다.

- ✅ **서버가 없습니다.** 이 프로그램은 100% 내 PC에서만 동작하며, 어떤 데이터도 외부로 전송하지 않습니다.
- ✅ **로그인은 키즈노트 공식 사이트에서** 이뤄집니다. 아이디·비밀번호를 중간에서 가로채지 않습니다.
- ✅ **비밀번호 저장은 선택 사항**이며, 저장하더라도 **윈도우 자체 암호화(DPAPI)** 로 보호되어 다른 PC에서는 복호화할 수 없습니다.
- ✅ **사진과 알림장은 오직 내가 지정한 폴더**에만 저장됩니다.
- ✅ **소스 코드 전면 공개** — 위 내용은 코드로 직접 확인하실 수 있습니다.

## 💡 자주 묻는 질문

**Q. 크롬을 쓰는데 작동하나요?**
> 네. 기본 브라우저가 무엇이든 상관없습니다. 프로그램이 윈도우에 내장된 **Microsoft Edge** 를 이용해 작업을 대행합니다.

**Q. 회사 PC(사내망)에서도 되나요?**
> 실행 자체는 됩니다. Edge 통신용 엔진을 배포 폴더에 함께 담아 두었기 때문에 별도 다운로드가 필요 없습니다.
> 다만 회사 네트워크(프록시)가 사진 서버를 막는 경우가 있어, **직접 다운로드 → CDP 경유 → 브라우저 경유 → 화면 캡처** 순으로 우회를 자동 시도합니다.
> 그래도 전부 막히는 환경이라면 **PDF 저장은 정상 동작**하니, 사진 원본은 가정 네트워크에서 받으시길 권장합니다.

**Q. 화면 글씨가 너무 크거나 작아요.**
> 4K High DPI 최적화와 해상도별 동적 스케일링이 적용되어 있어, 윈도우 '디스플레이 배율' 설정을 따라갑니다.

**Q. 잘 안 되는데 어떻게 알려드리나요?**
> 프로그램 상단의 **🔧 진단정보 복사** 버튼을 누르면 원인 진단 로그가 클립보드에 복사됩니다. 그 내용을 [이슈](../../issues)로 남겨주시면 확인하겠습니다.

## 🛠️ 개발자용

### 소스에서 직접 실행

```bash
pip install PyQt5 selenium Pillow requests
# msedgedriver.exe (Edge WebDriver)를 프로젝트 폴더에 준비
python kidsnote_saver.py
```

### 배포판 빌드

```bash
build_release_v1.bat            # 기본: 폴더(onedir) 배포 — 시작이 빠르고 임시폴더 경고가 없음
build_release_v1.bat onefile    # 단일 exe (시작 느림, 일부 보안 환경에서 종료 경고 가능)
```

빌드 결과 zip 1개를 GitHub Releases에 첨부하면 배포 완료입니다.

### 파일 구성

| 파일 | 역할 |
|---|---|
| `kidsnote_saver.py` | PyQt5 GUI, 다운로드/수집 스레드 |
| `kidsnote_engine.py` | Selenium 기반 수집·다운로드 엔진 |
| `build_release_v1.bat` | PyInstaller 배포 빌드 스크립트 |
| `test_*.py` | 점검용 스크립트 |
