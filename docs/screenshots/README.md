## ⚠️ 촬영 전 반드시 확인

이 저장소는 **공개**되어 있습니다. 한번 올라간 이미지는 되돌리기 어렵습니다.

- **다른 아이의 얼굴이 나오지 않도록** 하세요. 앨범 사진에는 반 전체가 찍혀 있는 경우가 많습니다.
- **아이 이름·반 이름·선생님 성함**이 보이면 가리거나, 캡처 범위에서 빼주세요.
- **아이디(이메일)** 가 보이지 않게 하세요. 비밀번호 칸은 어차피 가려지지만 아이디는 그대로 보입니다.
- 목록 화면(`02-list.png`)은 제목·날짜만 보이므로 비교적 안전하지만, 제목에 이름이 들어간 글이 있는지 살펴보세요.
- 결과 폴더(`04-result.png`)는 **파일 이름만** 보이도록 하고, 사진 미리보기(큰 아이콘) 대신 **자세히 보기**로 캡처하는 편이 안전합니다.

가릴 부분은 그림판으로 검은 사각형을 덮으면 충분합니다.
